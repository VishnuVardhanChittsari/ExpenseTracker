# 💸 Expense Tracker (Console-Based)

A simple and efficient Java console application that allows users to track their expenses. It supports user registration, login, expense management, and data filtering by date using a persistent MySQL database and JPA (Hibernate).

---

## 📌 Features

- 👤 User Registration and Login
- ➕ Add new expenses
- ✏️ Edit existing expenses (optional)
- 📄 View all expenses
- 📆 Filter expenses by date
- 🚪 Logout functionality
- 💾 Persistent data storage with MySQL

---

## 🛠️ Technologies Used

- **Java** (Core Concepts, OOP, Collections)
- **JDBC**
- **Hibernate (JPA)**
- **MySQL**
- **Maven**
- **Console-based UI**

---

### 🧰 Prerequisites

- Java JDK 8 or higher
- MySQL Server
- Maven
